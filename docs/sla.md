# 服务级别协议（SLA）— DBCool 企业支持

> 状态：**Wave 3 交付**（2026-10-30）。本页承诺需与已签署的服务协议一致才对客户生效；
> 未签署协议的社区用户不适用本页时限（见 [SUPPORT.md](../SUPPORT.md) 社区渠道）。

## 一、版本支持政策（Supported Versions）

| 版本线 | 状态 | 支持截止 |
|---|---|---|
| 2.1.x（当前） | ✅ 完整支持 | 下一大版本（2.2/3.0）发布后 **6 个月** |
| 2.0.x | 🟡 仅安全修复 | 2027-04-30 |
| < 2.0 | ❌ EOL | 已停止 |

规则：
- 安全修复只发往 **当前版本线 + 上一版本线**。
- 升级路径：任意 2.x → 最新 2.1.x（用 `scripts/upgrade.sh`，见升级 Runbook）。

## 二、响应时限（订阅用户）

| 级别 | 定义 | 首响 | 更新频率 | 处理目标 |
|---|---|---|---|---|
| L3 严重 | 数据丢失风险 / 登录与核心链路不可用 / 安全事件 | ≤ 1 小时（7×24） | 每 4 小时 | 24h 内根因初判，恢复优先 |
| L2 故障 | 非核心功能故障 / 明显性能退化 | ≤ 4 工作小时 | 每工作日 | 2 个工作日修复或 workaround |
| L1 咨询 | 安装 / 配置 / 使用 | ≤ 1 工作日 | 每 2 工作日 | 3 个工作日给出方案 |

计时起点：支持渠道收到**完整信息**（环境 + 日志 + 复现步骤）的时间。

## 三、SLA 不含什么（重要）

| 不含项 | 说明 |
|---|---|
| 自有业务代码缺陷 | 客户在平台之上自研的应用/脚本问题（可按 L1 咨询协助定位） |
| 第三方服务故障 | 钉钉/企微/飞书/微信/支付网关/云厂商侧故障 |
| EOL 版本 | Supported Versions 表之外的老版本 |
| 未授权环境 | 未购买订阅的生产环境不适用时限承诺 |
| 数据恢复承诺 | 平台提供备份与 PITR 工具链；**RPO 取决于客户配置的备份频率**，恢复演练需客户侧配合执行 |
| 硬件 / 网络基础设施 | 客户机房、虚拟化、存储层故障 |
| 超范围改造需求 | 走企业版附加组件或定制项目，不占用支持工时 |

## 四、客户义务

1. 按验收清单（`docs/acceptance-checklist.md`）完成上线验收并存档结果。
2. 保持升级：安全修复版本发布后 **30 天内**完成升级或提出书面风险接受。
3. 提供必要的访问与日志（最小权限原则）。
4. 生产环境必须启用备份（`pg_dump` + WAL 归档）并至少演练过一次恢复。

## 五、违约与救济

未达首响时限的工单，按协议约定以服务时长补偿。数据丢失类事件的赔偿上限以服务协议为准；
Apache-2.0 授权的软件本身不附带任何担保（见 [NOTICE](../NOTICE)）。
